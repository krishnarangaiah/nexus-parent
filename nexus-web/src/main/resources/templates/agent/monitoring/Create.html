How to Connect an Agent
  1. Register the agent above with a unique UUID
  2. Start the agent jar with the UUID: 
    java -jar nexus-agent.jar --agent.uuid=YOUR-UUID-HERE
  3. The agent will connect and appear as "Online" in the dashboard
  4. You can then send commands to the agent from the Command Console
